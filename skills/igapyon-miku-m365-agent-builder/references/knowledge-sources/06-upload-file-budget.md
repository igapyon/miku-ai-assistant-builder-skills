# Agent Builderのファイル枠配分

## 目的

Agent Builderへ端末から直接アップロードする埋め込みファイルを20件以内に収めながら、人間が準備した資料を優先し、残りの枠へ自動生成Knowledge sourcesを配置する。

20件はAgent Builder側の現行上限であり、実行時に最新のMicrosoft公式情報または利用者の実画面で変更が確認された場合は、その値を固定値として使わず見直す。

## 数え方

`manual-input/`を読み取り専用で棚卸しし、最終的に登録候補となる手動資料数を`M`とする。

- Markdownは一対一でDOCXへ変換するため、Markdown 1ファイルを1件と数える。
- 検証済みのDOCX、PPTX、XLSXなどは、それぞれ1ファイルを1件と数える。
- 未対応形式、未確認形式、管理用ファイル、サブディレクトリは数えない。ただし、採否が未確定のまま最終化を続けない。
- 同じ最終basenameを持つ候補は、件数調整のために片方を黙って除外せず、衝突として停止する。

人間が準備した資料を優先するが、自動生成Knowledge sourceを最低1件確保する。このため`M`は0以上19以下でなければならない。`M`が20以上なら、利用者へ19件以下への削減を求めて停止する。

## 自動生成枠

手動資料数を確定した後、自動生成に使用できる枠`A`を次で求める。

```text
A = 20 - M
```

入力元にある`miku-text-bundle`対応テキストのうち、安全上・技術上必要な理由で除外していないファイル数を`N`とする。内容の関連性、旧版、重複の推定だけで`N`を減らさない。`N`が0なら、自動生成Knowledge sourceを最低1件作る要件を満たせないため停止する。

目標とする自動出力数`T`は次で求める。

```text
T = min(N, A)
```

`N`が`A`以下なら、空き枠を埋めるためだけの不要な分割を行わない。実際の自動出力数が`A`未満になることは問題としない。

## max-charsの決定

選択済み自動入力を、実際に使用する文字コードと除外条件で読み取った合計文字数を`C`とする。`miku-text-bundle`へ渡す`--max-chars`の初期候補を次で求める。

```text
candidate = ceil(C / T)
maxChars = max(120000, candidate)
```

120,000文字は同梱`miku-text-bundle`の既定値を使った運用上の下限であり、Microsoftの製品制限ではない。入力が小さい場合に、ファイル枠を埋める目的だけで細かく分割しないために使う。

## dry-runと調整

1. `maxChars`を指定してknowledge-sourceモードをdry-runする。
2. dry-runの収集件数が`N`と一致することを確認する。不一致なら対象範囲、除外、文字コードを直し、件数計算からやり直す。
3. 推定Knowledgeファイル数が`A`以下なら、その値で本実行する。
4. 推定Knowledgeファイル数が`A`を超える場合は`maxChars`を増やし、`A`以下になるまでdry-runを繰り返す。
5. 本実行後の番号付きMarkdown件数も`A`以下であることを確認する。超過した場合は最終化せず、より大きい`maxChars`で再生成する。

dry-runの推定数を無理に`T`へ一致させる必要はない。ファイル境界、見出し、出典情報などにより結果が少なくなる場合は、そのまま採用できる。

## 記録

`work/preparation-status.md`へ、少なくとも次を記録する。

- 手動資料数`M`
- 自動生成枠`A`
- 適格な自動入力ファイル数`N`
- 目標自動出力数`T`
- 合計文字数`C`
- 採用した`maxChars`
- dry-runの推定Knowledgeファイル数
- 本実行で生成したKnowledgeファイル数
- 最終登録候補総数

最終登録候補総数が20以下であり、`agent-builder-input.md`のKnowledge sources一覧と`upload/`の実在ファイルが一致することを双方向に確認する。

## 例

- `M = 19`、`N = 100`なら、`A = 1`、`T = 1`として自動生成物を1件以内にまとめる。
- `M = 5`、`N = 3`なら、`A = 15`、`T = 3`とする。15件へ増やすための分割は行わない。
- `M = 0`、`N = 8`なら、`A = 20`、`T = 8`とする。
- `M = 20`なら、自動生成枠を確保できないため停止する。
- `N = 0`なら、自動生成Knowledge sourceを作れないため停止する。
